# Deprecated

`changelog-gen` is being deprecated, when it was initially developed
[git-cliff](https://git-cliff.org) wasn't as well established or fleshed out.
At this point, git-cliff provides all supported changelog generation
mechanisms, while providing more flexibility.

With that in mind, development on `changelog-gen` will cease.

As git-cliff does not provide release management, that part of changelog-gen
has been spun off as
[bumpversion-slim](https://github.com/NRWLDev/bumpversion-slim). This provides
a lightweight alternative to
[bump-my-version](https://github.com/callowayproject/bump-my-version). It does
not manage semantic version generation, instead relying on the output of
`git-cliff`.

## Using git-cliff

```console
> git-cliff --config pyproject.toml --bump -o CHANGELOG.md
> VERSION=$(git-cliff --bumped-version)
> bumpversion $VERSION
```

For anyone using standard configuration for changelog-gen, the following
configuration will replicate existing functionality.

```toml
[tool.bumpversion]
current_version = "0.0.0"
allow_dirty = true
allow_missing = true
commit_extra = ["CHANGELOG.md"]
allowed_branches = [
    "main",
]

[[tool.bumpversion.files]]
filename = "pyproject.toml"
pattern = 'version = "{version}"'

[tool.git-cliff.bump]
features_always_bump_minor = false
breaking_always_bump_major = false

[tool.git-cliff.changelog]
header = """
# Changelog\n
"""
body = """
{% if version %}\
    ## {{ version  }} - {{ timestamp | date(format="%Y-%m-%d") }}
{% else %}\
    ## Unreleased
{% endif %}\
{% for group, commits in commits | group_by(attribute="group") %}
    ### {{ group | upper_first }}
    {% for commit in commits %}
        - {% if commit.breaking %}**Breaking** {% endif %}\
        {{ commit.message | split(pat="\n") | first | upper_first | trim }}\
        {%- if commit.links %} {% for link in commit.links %}[{{link.text}}]({{link.href}}) {% endfor -%}{% endif %} \
        [[{{ commit.id | truncate(length=7, end="") }}](https://github.com/NRWLDev/changelog-gen/commit/{{ commit.id }})]\
    {% endfor %}
{% endfor %}\n
"""
trim = true
footer = "<!-- generated by git-cliff -->"

[tool.git-cliff.git]
link_parsers = [
    { pattern = "#(\\d+)", href = "https://github.com/NRWLDev/changelog-gen/issues/$1"},
]

commit_preprocessors = [
  # Remove issue numbers.
  { pattern = '\((\w+\s)?#([0-9]+)\)', replace = "" },
]
commit_parsers = [
    { message = "^feat", group = "Features and Improvements" },
    { message = "^fix", group = "Bug fixes" },
    { message = "^doc", group = "Documentation" },
    { message = "^refactor", group = "Refactor" },
    { message = "^style", group = "Styling" },
    { message = "^test", group = "Miscellaneous" },
    { message = "^chore|^ci", group = "Miscellaneous" },
]
sort_commits = "newest"
```
